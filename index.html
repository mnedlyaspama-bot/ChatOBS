Ссылка для OBS

  1. В OBS: Источники → + → Браузер.
  2. Вставьте ссылку в поле URL. Ширина 400, высота 700 (подберите под сцену).
  3. Фон прозрачный — свой CSS вставлять не нужно. Размер чата задаётся размером источника.
  4. Изменили настройки? Нажмите кнопку ещё раз и замените ссылку в OBS.
Страница открыта как локальный файл. Ссылка будет работать только на этом компьютере. Чтобы пользоваться везде, выложите obs-chat.html на хостинг (GitHub Pages, Cloudflare Pages и т. п.).
